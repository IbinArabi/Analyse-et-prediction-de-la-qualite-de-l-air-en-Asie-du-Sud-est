# Analyse-et-prediction-de-la-qualite-de-l-air-en-Asie-du-Sud-est
Projet : classification qualité de l'air (5 000 échantillons, 4 pays). Nettoyage, EDA, Random Forest (100 arbres, 80/20). Accuracy 95,1%. Facteurs clés : CO et proximité industrielle. Application : alerte précoce et surveillance automatisée. Python, Pandas, Scikit-learn.
